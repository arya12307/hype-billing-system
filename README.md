## 📋 What is Hype ERP?

Hype ERP is a **desktop ERP + billing software** built with Python & Tkinter, developed by **Nexuzy Lab** and led by **David (DevilOne)**.
It runs fully **offline**, syncs to **Firebase** when online, generates **GST-compliant PDF invoices**, and includes a full suite of 19 enterprise modules.

Every invoice, bill, and PDF generated by this software is permanently branded **Hype ERP** — this branding cannot be removed.

---

## ✨ Features

### 🧾 Core Billing
- GST-compliant invoice generation (SGST, CGST, IGST)
- Barcode/SKU product lookup
- Walk-in and named customer support
- Multiple payment methods (Cash, Card, UPI, Credit)
- Invoice PDF export with Hype ERP header/footer (permanent)
- Offline-first: all data stored in local SQLite

### 📦 Inventory & Stock
- Product management with category, HSN code, unit
- Auto low-stock alerts (highlighted in red/yellow)
- **Dead stock analysis** — detects items unsold for 90+ days
- Stock adjustment and purchase price tracking
- Min stock threshold per product

### 🏢 ERP Modules (19 Modules)

| Module | Code | Description |
|--------|------|-------------|
| Accounting | `account` | Chart of accounts, journal entries, trial balance |
| Invoice | `account_invoice` | GST invoice management |
| Asset | `account_asset` | Fixed asset register |
| Tax | `account_tax` | GST rate configuration |
| Banking | `account_statement` | Bank statement reconciliation |
| Sales | `sale` | Sales orders and reports |
| Purchase | `purchase` | Purchase orders and vendor bills |
| Inventory | `stock` | Stock movements and valuation |
| Manufacturing | `production` | BOM and production orders |
| HR | `company_employee` | Employee records and attendance |
| Payroll | `payroll` | Salary, PF, TDS, payslips |
| CRM | `crm` | Customer and vendor CRM + lead pipeline |
| Projects | `project` | Project and task management |
| Timesheet | `timesheet` | Billable hours tracking |
| POS | `sale_point` | Point of Sale with cart |
| Shipping | `stock_package` | Delivery and package management |
| Quality | `quality_control` | Quality control checklists |
| Marketing | `marketing` | Campaign management |
| Reporting | `analytic_account` | KPI dashboard and analytics |

### 🤖 AI Features
- 7-day AI sales prediction
- Smart product search (fuzzy matching)
- Anomaly detection on transactions
- AI price suggestions
- Auto model download & install on startup
- EXE-aware: models cached in `%LOCALAPPDATA%\HypeERP\models\`

### ☁️ Firebase / Cloud
- Real-time sync to Firebase Firestore
- Cloud database backup
- Offline queue — syncs when back online
- Multi-store support via Firebase
- Encrypted service account key (`.enc` file for EXE distribution)

### 📊 Reporting & Analytics
- Sales report with date filter
- Customer purchase history
- Dead stock & low stock report
- KPI dashboard (revenue, invoices, products, employees)
- GST summary report

### 💼 Other
- Multi-user login (admin / cashier roles)
- Tally-like accounting suite
- Settings: shop name, GSTIN, address, invoice prefix
- Splash screen auto-installer on first run
- PyInstaller EXE + Inno Setup installer support
- Single entry point: `python main.py`

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/david0154/hype-billing-system.git
cd hype-billing-system

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run
python main.py
```

**Default login:** `admin` / `admin123`
